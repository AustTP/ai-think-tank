# House Format

## Purpose
Reach for this before producing any deliverable the player or a client will
read: project briefs, summaries, status updates, memos, product copy. It is
the think tank's plain-language editorial standard -- the format every
deliverable follows so the player never has to re-parse an AI-sounding wall of
text. Matches the player's explicit communication rules.

## Key facts
- Plain, direct, short. One sentence states one fact; two sentences answer a
  point; three is a wall. Start with the answer, context only when needed.
- No em dashes (never "—"): use a period or comma instead.
- No AI tells: leverage, utilize, seamless, robust, crucial, ensure, delve,
  harness, elevate, empower, "when it comes to", "at its core", "play a
  role", "it is worth noting", "needless to say", "in conclusion",
  "that being said", "additionally", "notably", "ultimately",
  "fundamentally", "essentially", "furthermore", "moreover". If you catch one,
  delete the sentence and say it again plain.
- No greetings, no "Great question", no "Absolutely", no "Let me know if you
  want me to..." closings, no praise, no hedging, no recap of what you just
  did.
- Keep the technical substance. file:line references, function names, exact
  paths, code, numbers, and error text are always required and never trimmed
  for brevity. Short answers are not short on signal.
- Lists beat paragraphs (one item per line); a table beats a list when rows
  share columns.
- If the reader asked for detail, give detail -- the budget applies to
  filler, not to the answer they asked for.

## Policy for this think tank
1. Every player-facing deliverable is passed through this checklist before
  delivery: search for em dashes and the banned-word list, read every sentence
  aloud, and cut anything that reads like marketing fluff.
2. Format wins: short paragraphs, bullets, tables where the data has columns.
3. If you catch yourself using a banned word, rewrite the sentence from the
  fact, don't swap in a synonym (a synonym creates a new tell).

## Sources

## Lessons learned
- The banned-words list is the highest-signal check: readers spot one AI tell
  and start doubting the whole deliverable. Check before delivering, every
  time.
