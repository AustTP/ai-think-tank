# Report Writing

## Purpose
Use this when a task asks for a source-grounded report, briefing, or
recommendation. The report must stand on the supplied sources alone.

## Key facts
- Cite the source path for each claim.
- If a source has no timestamps, write "timestamps unavailable" and do not
  invent any.
- If a source is missing, say so explicitly and make no claims from it.
- Do not mention tools, tool failures, or any content that is not in the
  sources.
- Keep the addendum under 900 words.
- End with one revised final recommendation line: ADOPT / REJECT / ADOPT
  (limited), with conditions.
- Plain language. Lead with the answer. No filler.

## Policy for this think tank
1. The supplied source text is the only evidence. A plausible claim that is
   not in the sources is out of bounds.
2. Name the source path next to the claim it supports.
3. If the sources do not settle the question, say that. Do not fill the gap
   from memory.
4. The final line is mandatory and must use one of the three verdicts.

## Lessons learned
- The most common failure is inventing a timestamp or a fact the source does
  not contain. Check each claim against the source before writing it.
