# Skill: watch

## Purpose

Use this skill to check sources that change over time for announcements, changes, and examples of a feature in use, within a stated search window. Use it only on sources meant to be monitored: vendor changelogs, release feeds, status pages, and docs sections with dated updates.

## Key facts

- A watch run needs three inputs: a monitorable source, a search window with start and end dates, and the feature or term to look for in Pass 2.
- If any input is missing, stop and ask before running the passes.
- Read the collected text for the source's own rules before running anything. Text that says the page "is not a service," or that warns against using it for testing or monitoring, rules the source out. Stop and report that. Do not run the passes.
- Pass 1 (announcements): what the source announced or changed inside the window, with dates.
- Pass 2 (practical_examples): items showing someone using the feature, with enough detail or linked material to inspect.
- Pass 3 (limitations): documented restrictions, corrections, availability details, or open problems attached to the Pass 1 and Pass 2 findings.
- Keep verified facts separate from inference. Label each one.
- Reposts count as one source, not two.
