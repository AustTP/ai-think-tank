## What this is

A reusable client-side simulation engine in vanilla JavaScript (ES modules, no
framework), built by the think tank's agent team over multiple review cycles.

## Contents

| Module | Purpose |
| --- | --- |
| `sim-engine.js` | Fixed-timestep World with a pluggable systems registry |
| `rng.js` | Seeded deterministic RNG (`RNG` / `Rng`) |
| `boids.js` | Boids flocking (separation, alignment, cohesion) |
| `predatorprey.js` | Predator-prey ecosystem (chase/flee/hunger dynamics) |
| `sir.js` | SIR epidemic (susceptible/infected/recovered) |
| `ca-engine.js` | 2D cellular automata (Life, Seeds, HighLife, Day&Night) |
| `world.js` | World/systems composition used by the harness |
| `weatherstation*.js` | Browser harness wiring: canvas, sliders, live stepping |
| `weatherstation-headless.js` | Headless mode: step N steps, export JSON state |
| `index.html` + `main.js` | Demo harness page |

Tests: `*.test.mjs` (node:test). API docs generated by
`scripts-gen-api-docs.mjs`; README markers maintained by the same script.
