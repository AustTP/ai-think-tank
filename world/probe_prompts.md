## probe-zero
The village is deciding whether to accept a peer-reviewed deliverable that a
worker claims is complete but has never been run. Write 3-4 concrete sentences:
should we accept it, and what single verification step would you require first?
Be specific, not generic.

## probe-one
A long-running background agent is stuck: it walked to a task location but its
task state never updated, and another process holds the same task id. Diagnose
the most likely cause and give the exact recovery action. Two sentences, decisive.

## probe-two
Write a small, self-contained Python function that takes a list of (task_id,
deadline_ms) tuples and returns the ids sorted by urgency (soonest deadline
first), skipping any with no deadline. No imports beyond datetime. Include the
function only, no explanation.

## probe-three
A villager filed a peer report against a coworker for "not doing their share."
Before acting on it, list three distinct signals you would check to decide
whether the report is credible. Keep it to a tight bulleted list.

## probe-four
In one line, explain what the Model Context Protocol (MCP) is and why connecting
tools through it beats copy-pasting data into a chat window.
