World — collision grid editor

Pick a mode, then click/drag on the map. Block and Erase paint cells; Pan drags the view around while zoomed in (scroll wheel zooms too, centered on the cursor -- this pan/zoom is an editing convenience only, the actual game canvas doesn't have it). Loads the current auto-generated collision_grid.json (from CLIPSeg) so you're correcting it, not starting from scratch. Save writes straight to collision_grid.json on disk -- reload world/index.html afterward to play with the update.
